## App map

This repo's architecture map is in `docs/app-map/` (the app-map skill). Whenever you change code,
keep the map in the same change: run `.agents/skills/app-map/scripts/app-map changes docs/app-map`,
and if it lists a module, follow the skill's "Update" section (edit only what the change
affects in that module's `.md`, then `build`, `verify`, `sync`). Commit the map with the code.
